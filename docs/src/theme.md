# Appearance

Open **Settings > Theme** and choose a preset. The change applies immediately to this browser.

| Theme | Appearance |
|---|---|
| Dark | Deep blue panels and the standard LocalSky palette. |
| Light | Bright surfaces with the same app layout. |
| Auto | Follows the operating system's light or dark preference. |
| High contrast | Black and white with reduced visual effects. |

The preference is stored in the browser. It does not change other devices or travel in a server backup. Clearing site data resets it to Dark.
